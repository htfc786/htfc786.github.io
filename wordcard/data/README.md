# 数据目录

数据全部是普通 JSON 文件，通过 HTTP 静态获取，不需要后端接口。

## 词表格式

与 zzti-web 的单词卡数据一致，在此基础上增加可选的 `i` 字段：

```json
[
  { "front": "abandon", "back": "v. 放弃；抛弃", "content": "/əˈbændən/", "i": 1 },
  { "front": "benefit", "back": "n. 好处；v. 使受益", "content": "/ˈbenɪfɪt/", "i": 2 }
]
```

| 字段 | 必填 | 说明 |
|---|---|---|
| `front` | 是 | 正面（单词） |
| `back` | 否 | 反面（释义） |
| `content` | 否 | 附加信息，例如音标、词性、例句 |
| `i` | 否 | 序号。有它时，卡片上印的序号就是它；没有时按数组顺序从 1 编号 |

`front` / `back` / `content` 里的换行直接写 `\n`。数组顺序就是制卡顺序，`i` 只决定卡片上印的序号和按范围筛选时的依据。

也兼容 zzti-web 题库里的 `q` / `ans` / `con` 命名。

## 增加一套词表

1. 把 JSON 文件放进本目录，例如 `cet4.json`。
2. 在 `catalog.json` 的 `datasets` 里加一项：

```json
{
  "id": "cet4",
  "name": "四级核心词",
  "file": "cet4.json",
  "description": "可选说明"
}
```

刷新导入页即可在下拉菜单里看到。文件名只写本目录内的相对路径，页面不会去请求任意 URL。
