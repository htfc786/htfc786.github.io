# 单词卡制作（HTML + CSS 排版版）

用 **纯 HTML + CSS** 把单词卡排成 A4 页面，直接打印或"另存为 PDF"。
不经过 canvas、不生成图片，文字始终是**矢量文本**。

```
index.html          界面（左：参数面板，右：预览 + 可视化编辑）
src/print.css       排版 & 打印核心 —— 纸张、网格、安全区、卡片、双面（可整份复用）
src/card.js         排版逻辑 —— 分页、正反面镜像、尺寸计算、DOM 生成、自动缩字号
src/app.js          界面逻辑 —— 参数面板（schema 驱动）、可视化编辑、打印、localStorage
src/ui.css          界面样式（打印时全部隐藏）
tests/smoke.sh      打印冒烟测试：页数 / 尺寸计算 / 矢量文本
tests/edit.mjs      可视化编辑的端到端测试（CDP 模拟真人改字）
```

直接双击 `index.html` 就能用（无构建、无依赖）。

## 为"打印后裁剪"做的设计

- **纸张留白默认 0**：卡片直接铺到纸边，裁的时候不用先修边。
  最外圈被打印机不可打印区吃掉一点是预期内的 —— 那边本来就没内容。
- **卡片间距默认 0**：相邻卡片共用同一条裁切线，一刀下去就是两张卡。
- **没有圆角**：裁完就看不见了，索性不做。
- **卡片尺寸不用填**：由「纸张 − 留白 − 间距」÷ 每页张数算出来，面板底部实时显示
  （例：`卡片 74.3 × 42.0 mm · 内容可用 68.3 × 36.0 mm · 每页 20 张`）。
- **安全区（四边独立）**：卡片四周的边带不渲染内容，留给你用夹子夹、打孔或装订。
  **四边分别设置** —— 只在上面夹夹子就把「上」调到 10~15mm，其余三边留 0，版面一点都不浪费。
  内容会在这个"缩小的可用区"里重新居中。屏幕上用蓝色虚线画出四边的边界，打印时不会画出来。
  **背面会自动镜像**（见下一节），所以四边只需要按正面的物理方向填一次。
  卡片序号会自动躲进安全区内侧的角上，裁完仍在卡片上。

## 背面的镜像（重要）

背面不是"另一张纸"，而是同一张卡的另一面，所以**整张背面纸是正面纸的镜像**。
「背面版式」选的镜像方式作用在两层：

1. **卡片落在哪一格** —— 让背面第 N 张卡正好落在正面第 N 张卡的背面
2. **卡片内部的几何** —— 安全区四边、内容整块位置、行内对齐、附加信息上下顺序、
   卡片序号所在的角，都按同一个变换翻过去

| 背面版式 | 卡片换格 | 安全区 | 内容位置 | 卡片序号 |
|---|---|---|---|---|
| 左右镜像 | 列反转 | 左 ↔ 右 | 左 ↔ 右 | 右下 → 左下 |
| 上下镜像 | 行反转 | 上 ↔ 下 | 上 ↔ 下，附加信息移到正文上方 | 右下 → 右上 |
| 旋转 180° | 行列都反转 | 两轴都翻 | 两轴都翻 | 右下 → 左上 |
| 不镜像 | 不动 | 不动 | 不动 | 不动 |

**文字本身永远不镜像**（镜像了就读不了），翻的是它摆放的几何。

实测例子（左边夹夹子 25mm + 左右镜像）：正面每张卡的内容靠右，给左边的夹子让位；
背面每张卡的内容靠左让位 —— 两边让开的是**同一条物理边**。
如果不镜像，背面就会把内容留在夹子那一侧，直接被夹住。

正反面故意要做成不同版式的话，可以在「双面打印」里关掉 **背面位置跟随镜像**，
背面就完全按面板设定的方向印。安全区和卡片序号不受这个开关影响 —— 它们必须对齐物理边。

## 三个内容块，各自独立排版

正面 / 反面 / 附加信息 三块各有自己的一套样式：字体、字号、字重、行高、颜色、行内对齐。
正反面还各有「整块位置」和「垂直位置」。

**"文字块居中，但每行从左边起排"** = 整块位置选「居中」+ 行内对齐选「左对齐」：

| 行内对齐 | 整块位置 | 效果 |
|---|---|---|
| 居中 | 居中 | 每行各自居中（默认） |
| **左对齐** | **居中** | **每行左端对齐成一块，整块居中** |
| 左对齐 | 靠左 | 常规左对齐排版 |
| 左对齐 | 居中 + 垂直靠上 | 同上，但靠卡片顶部 |

卡内换行：在预览里按 Enter，或在文本框里写 `\n`。

## 可视化编辑

预览里的文字 **点一下就能直接改**：

- Enter 换行，Esc 退出编辑
- 粘贴自动清洗成纯文本，不会带进网页样式
- 改完右侧文本框自动同步（每行一张卡）
- 附加信息如果设置成"两面都印"，改一面另一面会跟着变
- 参数面板里的「预览里直接编辑」可以关掉，关掉后就只能看不能改

## 打印设置（这几项必须对，CSS 管不了）

1. **边距 = 无**（页面留白已经由 CSS 的"纸张留白"控制）
2. **缩放 = 100% / 默认**，别让浏览器"适应页面"自动缩放
3. **取消勾选页眉页脚**
4. 双面打印：开启"双面打印"，翻转方式选 **长边翻转**；选错就用下面的对位测试纠正
5. 导出 PDF：目标打印机选 **"另存为 PDF"**，得到的就是矢量 PDF

## 双面卡片的对位（唯一需要实测的一步）

背面格子该落在哪一格，取决于打印机 + 驱动 + 纸张方向 + 长边/短边翻转，**没有跨机器通用的答案**，
所以做成了下拉选项：

1. 点左侧 **「对位测试数据」**（会自动变成 2×2、实线边框、安全区 0、数据 1|1 2|2 3|3 4|4）
2. 双面打印这一页
3. 对着光看：正面的 `1` 是否正好压在背面的 `1` 上
4. 不重合就换「背面版式」里的一项（左右镜像 / 上下镜像 / 旋转 180° / 不镜像），重打一张

选对之后，正常数据就一直沿用这个设置（配置存在 localStorage 里）。

## 打印时的几个坑（已在代码里处理）

- **每页多吐一张空白页**：`.sheet` 高度刚好等于纸张时，Chrome 会四舍五入导致溢出。
  所以 `--page-h` 用的是 `209.9mm`（纸张 210mm 减 0.1mm）；`print.css` 的 `@media print`
  里也强制清掉了宿主页面的 `body` 边距（那 8px 默认边距同样会顶出一页空白）。
- **纸张方向**：`@page { size: A4 landscape }` 由 JS 按配置动态改写 `<style id="page-rule">`。
- **底色/边框打不出来**：`print-color-adjust: exact`，否则浏览器为了省墨会丢掉背景。
- **长释义溢出卡片**：CSS 做不到"自动缩到装得下"，`CardKit.autoFitCell()` 逐格测量内容，
  超了就按 0.5pt 步进降字号（下限可配）；内容改短了字号会自己涨回去。不在意可以关掉。
- **屏幕专用样式绝不污染打印**：预览缩放、安全区参考线、编辑高亮全部写在 `@media screen` 里。

## 想加一个新的可调项？

在 `src/app.js` 的 `SCHEMA` 里加一行，然后在 `src/print.css` 里用变量取值即可：

```js
{ p: 'card.safe.top', t: 'number', label: '上', unit: 'mm', min: 0, max: 30, step: 0.5 }
```

支持的类型：`select` / `number` / `color` / `check`。变量写入在 `src/card.js` 的 `applyPageVars()`。

## 测试

```bash
bash tests/smoke.sh      # 打印：页数、尺寸计算、安全区四边、矢量文本、纵向纸张（7 项）
node tests/edit.mjs      # 可视化编辑：回写数据、重渲染保留、两面同步（4 项）
```

两个脚本都用无头 Chrome 真跑一遍：`smoke.sh` 把页面打成 PDF 再核对页数和
`pdftotext` 能否提取文字（能提取就说明没被光栅化）；`edit.mjs` 走 CDP 模拟真人改字。
需要 `google-chrome`、`pdfinfo` / `pdftotext`（poppler）。

## 搬到 Vue（zzti-web 的 CardPage）

`src/card.js` 只依赖 DOM、不依赖框架，可以几乎原样搬到 `src/core/card.ts`：

- `defaultConfig()` / `cardGeometry()` → 配置类型与"卡片尺寸"计算
- `paginate(cards, cfg)` → 取代原来的 `createPaperData()`
- `createSheet()` + `print.css` → 取代 `createImage()` 里的 html2canvas
- `autoFitCell()` / `parseCards()` / `cardsToText()` → 新增能力
- `createPdf()`（jspdf + 图片）→ 直接删掉，改成 `window.print()` 出矢量 PDF；
  要"一键下载 PDF"就在服务端用 Puppeteer `page.pdf({ format:'A4', printBackground:true })`，
  把同一份 DOM 和 CSS 原样复用，依然是矢量文本
